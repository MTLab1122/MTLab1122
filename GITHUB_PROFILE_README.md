## How I Build

1. **Clarify** — understand the user, goal, content, and success criteria.
2. **Structure** — shape the information architecture and reusable component boundaries.
3. **Design** — establish hierarchy, responsive behavior, color, typography, and interaction intent.
4. **Build** — write typed, semantic, maintainable code.
5. **Polish** — add motion, keyboard states, metadata, and performance details.
6. **Ship** — deploy, inspect, learn, and improve.
